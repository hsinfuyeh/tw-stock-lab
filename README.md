# tw-stock-lab 臺股研究台

## 10 交易日 +5% 研究（今日名單）

每日盤後更新後，今日名單顯示最多 10 檔量價研究候選，觀察下一個交易日開盤進場後，10 個交易日內能否以至少 +5% 的毛價差出場。進場日算第 1 日；只比較價格，不含稅費與股息，沒有固定停損。每日候選隨快照原樣保存，期滿後分別核對「最高價曾觸及」、「高過目標價一個升降單位的較保守可成交機會」以及第 10 日收盤價差。日線無法證實委託排隊及實際成交。

目前沒有完整歷史上市／下市母集合、公司行動及逐筆成交驗證，也沒有足夠的逐日樣本外校準資料。因此今日名單先明確標示為**量價研究候選**，不顯示達標機率，正式推薦清單可以為空；舊六期限分析移入參考區。每日會保存全部合格標的的排序並核對，到至少80個不同訊號日、分組樣本充足後，以前段資料估計前10%排序組的達標頻率，隔10個訊號日後留出最近20日檢驗。只有保留期的達標率及Brier分數同時優於全組基準，才會啟用該類標的的正式推薦。此頻率屬組別估計，不是個股保證；連日訊號重疊，仍須持續觀察。股票型 ETF 先採保守篩選：只納入名稱或追蹤指數可明確識別為台股者，含主動式；區域不明者暫排除，這不是完整的台股 ETF 名單。

本階段從現有 TWSE 日價量建立研究基準；法人、融資融券、公告、營收與 ETF 折溢價尚未通過「當時可得時間」及樣本外增益檢驗，故不會暗中加權。既有 36 個月資料以目前上市名單回填，不能用來宣稱無存續偏差的成功率。網站更新與資料來源限制見下文。

上市普通股與股票型原型ETF的盤後研究網頁。今日名單的兩週候選只選可明確識別的台股標的；舊六期限參考區仍保留原本的台灣及海外股票型ETF涵蓋範圍。排除上櫃、存託憑證、債券、槓桿及反向ETF；外幣加掛ETF保留於舊研究清單並顯示排除原因。

## 網頁

### 社群聲量（雲端收集）

新增獨立「社群聲量」頁籤，提供近 24 小時／7 天與平台篩選，每頁十檔。統計不同公開主貼文的提及篇數，不含留言、圖片文字；同平台同篇同股票只算一次。原文連結可核對。此指標不參與今日名單量價分數。

GitHub Actions 在行情更新後執行 `python social_update.py`，將結果寫入 `dist/data/social.json` 並保存在研究資料中。PTT 限最近 12 頁、150 篇及五分鐘；Dcard 股票板限五頁、每頁100篇標題摘要；Threads 搜尋「台股／股票／ETF」，每詞至多三頁、每頁50篇。均為有上限的觀察樣本，不代表完整全平台排行。社群收集失敗不阻擋行情頁發布。

Threads 使用官方搜尋 API。需在 Repository Settings → Secrets and variables → Actions 設定 `THREADS_ACCESS_TOKEN`，並具備公開關鍵字搜尋的有效授權；不得提交 token 或將其放入公開網站。未設定顯示「尚未授權」。Dcard 公開 API 實測為403，目前需另接入雲端可用資料服務；失敗顯示「收集失敗」，不以零篇偽裝已取得。前端各平台會顯示取樣範圍、掃描篇數和檢查時間，缺漏來源以「—」呈現。金鑰由使用者在 GitHub 設定，請勿貼到對話中。

本機可用 `python social_update.py --data-dir data --output dist/data/social.json` 執行相同收集流程。社群與行情更新日期分開；超過30小時未更新會提醒。七天統計僅限實際取得的貼文，資料缺漏、搜尋／掃描上限及初次回填範圍都會影響涵蓋程度。

導覽分為「首頁」「今日名單」「其他排行」。首頁可搜尋目前上市股票及股票型 ETF 的代號／名稱（台、臺通用），點選個股詳情查看盤後行情、K 線與六期限歷史情境分析。今日名單保留最多十檔的十交易日動能觀察。

其他排行提供成交金額、漲最多、跌最多、量暴增、創 20 日新高、創 20 日新低、波動小；搜尋與各排行每頁最多十檔，可用上一頁／下一頁瀏覽。每日漲跌以相鄰市場交易日收盤價計算；量暴增至少為前二十日平均量的 1.5 倍；新高／新低為收盤突破前二十日最高／最低價；波動採二十個日報酬的標準差。排行只比較新臺幣標的，缺漏或公司行動影響的指標排除，不是預測報酬或交易推薦。未還原價格與既有上市集合限制仍適用。

## 每日更新

GitHub Actions每日台灣19:15啟動（UTC11:15），22:47再補檢一次（UTC14:47），完成後自動發布。相同資料不會重建研究快照。電腦可關機；不是盤中即時報價。GitHub排程可能延遲，公開專案長期無活動也可能停用排程，請以網頁資料日與Actions狀態為準。休市日檢查後保留最近交易日。

首次需建立36個月全市場歷史，可能數十分鐘以上。後續只重抓近期行情與母集合，從現有資料增量分析。快取可續跑；另存3天公開資料備份artifact。若快取／備份均遺失則重新下載。初次資料也可由initial-data release恢復；舊seed僅作歷史快取，仍須更新至最新共同交易日。

失敗不發布新站、不把舊價格當作當日資料。停牌、缺資料、新上市歷史不足仍列在母集合並保守排除。網頁最多提供最近3份研究快照；原始研究記錄保留於資料庫與備份。Actions可手動Run workflow重新更新。

### 手動取得當日盤後資料

1. 網站點「手動更新／查看進度」，開啟本專案的 GitHub Actions。
2. 登入對本專案有寫入權限的 GitHub 帳號，按 **Run workflow**，選 **main**，再按 **Run workflow**。
3. 等待分析與發布都成功，再回網站按「讀取最新結果」，核對共同資料日。

「讀取最新結果」本身不觸發資料抓取。雲端抓取採保守盤後界線：台灣19:00前只採用前一日以前已完成的行情；19:00後才納入官方已提供的當日資料。休市不會產生當日行情。全市場重新分析需要數分鐘以上，GitHub排程可能延遲或未觸發，不能保證19:15即有新報表。網站只顯示最後成功發布的快照；執行中或失敗原因請看更新進度。22:47補檢仍使用GitHub排程，並非獨立監控或準時保證。

## 研究口徑及限制

- 來源為TWSE上市公司基本資料、ETF e添富分類、MI_INDEX、FMTQIK與官方開休市日。不同官方端點仍是同一來源，**未完成獨立跨供應商交叉檢核**。
- 以資料日為訊號日，次一實際交易日開盤模擬進場，各曆日期限休市順延到交易日收盤。
- 股票賣出稅0.3%、ETF0.1%；双邊手續費0.1425%與滑價0.05%。費率為研究假設，不含最低手續費、換匯、股利及個人稅負。
- 使用未還原價格，X調整與缺漏窗口排除。MI_INDEX無完整個股月表註記，未標示公司行動可能未被辨識。
- 歷史相似樣本平均及比例**尚未校準，無法保證未來收益**。目前上市集合有存續偏差，時間前推樣本有重疊，不是已驗證完整交易策略。
- 尚未加入基本面、籌碼、ETF淨值折溢價、盤中成交條件及10交易日+5%新策略。

## 本機驗證與執行

Python 3.12+、Node 22+：

```sh
pip install -r requirements.txt
python -m unittest discover -s tests -v
node --test tests/ui.test.mjs
python cloud_update.py
python -m http.server 8767 --directory dist --bind 127.0.0.1
```

`data/`與`dist/`不提交git；Pages只上傳靜態網頁與公开行情分析，不上傳個人對話、憑證、完整作業目錄或第三方工具下載檔。

原本本機自選清單模式仍可用 `python app.py serve`，但和雲端全市場模式請使用不同資料目錄。
