# tw-stock-lab 全上市研究與雲端發布

## 需求與決策

依使用者要求，建立 hsinfuyeh/tw-stock-lab 與 GitHub Pages，讓手機與外部電腦讀取盤後研究。每日台灣時間19:15由GitHub Actions更新，不依賴個人電腦。使用者已確認涵蓋上市普通股及國內／海外股票型ETF（含主動式），排除債券、槓桿、反向ETF；不擴及上櫃。

採「雲端批次計算＋靜態發布」。Pages不能執行Python後端，因此發布預先計算的JSON、逐檔詳情與CSV；篩選排序在瀏覽器執行。原本本機工具保留於tw-market-lab，新專案只移入產品程式與測試，不上傳分享對話、第三方下載套件或個人設定。

## 資料與覆蓋

- TWSE上市公司基本資料提供普通股母集合；ETF e添富Stock/Vanilla提供ETF集合，保留上市日期。
- MI_INDEX每日全市場行情下載36個月交易日；FMTQIK提供實際交易日，官方開休市日提供未來目標日。初次歷史建置可較久，以快取續跑；不將未完成初始化稱作全市場完成。
- 僅解析明確欄名的表格，核對日期、OHLC、重複代號；保留X除權息標記，遇不明調整與缺資料保守排除。來源皆TWSE，不能稱獨立交叉檢核。
- 每檔沿用六個曆日期限、成本、近鄰基準及時間前推驗證。缺當日行情／停牌／歷史不足仍列在母集合，結果為排除且數值空白；不使用舊價冒充當天。
- 每日重新取得母集合，新上市自動加入；使用目前上市集合，歷史結果有存續偏差，不宣稱全市場歷史回測無偏。

## 發布與可靠性

- 所有交易日行情抓取成功才發布新結果，單檔排除可發布並顯示總檔數、可分析及排除數。
- 網頁首頁只載入摘要，逐檔詳情分檔延遲載入；相對路徑支援/tw-stock-lab/，手機可查詢代號／名稱、股票ETF篩選、期限與排序。
- GitHub Actions每日UTC11:15（台灣19:15）執行，也可手動執行；GitHub排程可能延遲。休市保留資料日期並顯示最後檢查時間。
- 快取與Actions持久化artifact保存公開行情及研究狀態，快取遺失時嘗試恢復artifact；仍遺失則重新建置，不用空資料覆蓋舊站。備份受平台保留期限約束。
- 更新失敗不發布，舊頁面標示資料日、預定更新時間及逾期提示；Actions保留失敗日誌。網站不含憑證、交易功能或伺服器寫入端點。
- 目前比例未校準，擴大範圍不等於提高準確度；後續多來源與新策略仍另案進行。

## 驗收

分類涵蓋6碼與A尾碼、排除非股票ETF；錯日期與缺欄拒收；X標記與停牌排除；靜態路徑、分檔、排序、搜尋及CSV驗證。跑全套Python／Node測試；真正全市場初始化，核對母集合與發布檔數；最後驗證公開Pages網址及排程設定。
