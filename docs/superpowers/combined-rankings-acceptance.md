# 其他排行：法人與社群整合驗收

日期：2026-10-19。使用者確認法人排行同時提供淨額及買賣總量，依既有頁面擴充設計直接在 `local/research-upgrade` 實作。本機資料及原排名不改寫，未推送 GitHub 或部署 Cloudflare。

## 功能

- 「其他排行」分為量價排行、法人籌碼、社群聲量三組。
- 量價排行保留原七種排行；社群保留 24 小時／7 天、平台篩選、來源狀態、分頁、原文依據及更新操作。原 `#social` 導覽仍可開啟整合頁，控制器及 DOM 各只有一份。
- 法人選外資、投信、自營商；計算方式選淨額或總量；方向選買或賣，共十二種排行。期間支援單日與近五個實際交易日，標的可篩普通股／股票型 ETF，每頁十筆。
- 本榜排序數量欄置於標的後第一欄並標色，手機直接可見；買進、賣出、淨額仍分欄可核對。收盤、漲跌、幣別與個股詳情保留。
- 新增唯讀 `/api/institutions?sessions=1|5&id=...`，只用保存的官方觀測，不抓資料、不更新排名、不修改研究結果。靜態模式不請求這個本機 API。

## 計算口徑

外資採「外陸資（不含外資自營商）」欄位；不重複加入外資自營商。投信採各自買進、賣出及官方淨額。自營商總買進／總賣出分別加總自行買賣與避險，淨額保留官方自營商買賣超合計。

原始單位為股，不把股數當成投入金額。買超列淨額大於零，由大到小；賣超列淨額小於零，由最負開始；買進／賣出總量各列大於零，由大到小。同值以代號固定順序。零值不列為買超或賣超，缺資料不補零；五日需每一天都具備對應欄位與正確股數單位才累計。

回顧排行使用目前保存的該資料日官方版本，顯示資料日、窗口、首次觀測與來源檢查時間，明示不代表原訊號當時已知。來源失敗時保留舊觀測並標示錯誤。個股價格只採相同快照資料日，有缺價就顯示空值。
