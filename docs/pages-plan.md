# 執行計畫

規格：[pages-design.md](pages-design.md)。本次使用者已指示建立與發布，直接在本次執行，不重複要求授權。新獨立目錄保留原型不受影響。

1. 全市場資料：先測試分類、每日表格、錯日期、除權息及停牌；實作MarketClient與MarketService，沿用研究模型。用官方樣本及實際完整下載驗證。
2. 靜態出版：先測摘要／詳情分離、來源、CSV、無快照拒絕；實作靜態匯出和雲端CLI。原本API模式仍可執行。
3. 網頁：測試搜尋與路徑選擇，實作Pages模式、延遲詳情、搜尋、更新時間及覆蓋說明，保留六期限／四排序。
4. 雲端：Actions每日19:15、手動啟動，資料cache/artifact恢復與保存，失敗不部署。僅明確列入產品檔案提交至新repo。發布前檢查無個人資料及機密。
5. 完整驗證：所有自動測試、實際全市場覆蓋／公開Pages瀏覽器／官方網站抽樣核對。獨立審查發布邊界、資料口徑、失敗復原。

Review focus：ETF分類API是否真的套用篩選；新股無歷史時無法估計；公司停牌仍應留於覆蓋分母；既有資料artifact丟失；Pages子路徑與詳情載入失敗不顯示錯股；MI_INDEX價格調整資訊限制。
